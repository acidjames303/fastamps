# fastamps

## Stickman hillclimb (SmartFunction)

Continuous agent task to audit and improve the SmartFunction stickman on **Home** and **Work** only.

| Path | Purpose |
|------|---------|
| `stickman-hillclimb/AGENT_TASK.md` | How the looping agent works |
| `stickman-hillclimb/RUBRIC.md` | Quality scores + must-fix gates |
| `stickman-hillclimb/prompts/NEXT_BASE44.md` | **Paste this into Base44** each round |
| `stickman-hillclimb/iterations/` | Score history |
| `stickman-hillclimb/scripts/playtest.mjs` | Automated Home/Work playtest |

### Run playtest
```bash
cd stickman-hillclimb
npm install
npm run playtest
```
